# Room Booking Service

Сервис бронирования переговорок на Go, PostgreSQL, chi и pgx.

## Что реализовано

- `/dummyLogin` с JWT для ролей `admin` и `user`
- создание и просмотр переговорок
- создание расписания доступности переговорки
- ленивое формирование слотов при запросе доступных слотов
- создание и отмена брони
- список своих броней и список всех броней с пагинацией
- `/_info`, который всегда отвечает `200`
- unit- и e2e-тесты

## Принятые решения

- Слоты формируются лениво при запросе доступных слотов, а не отдельным фоновым джобом.
- Для активной брони на слот используется ограничение в базе данных, чтобы исключить двойное бронирование.
- `dummyLogin` выдает фиксированные UUID для `admin` и `user`, чтобы стабильно тестировать владение бронями.
- Отмена брони сделана идемпотентной: повторный вызов на уже отмененной брони возвращает актуальное состояние.

## Как запустить

```bash
docker compose up -d --build
```

Сервис доступен на `localhost:8080`.

## Makefile

- `make up` - поднять зависимости и сервис
- `make seed` - заполнить базу тестовыми данными

## Тесты

```bash
go test ./... -cover
```

Для E2E-тестов нужен доступ к PostgreSQL через `DATABASE_URL` или поднятый `docker compose`.
